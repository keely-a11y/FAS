Description

Ground-floor studio and retail space below four live-work lofts, designed for the creative industries cluster developing in this part of Culver City. The commercial level is sheltered beneath a deep canopy that defines the street edge, while the residential lofts above are set back to allow a landscaped terrace for each unit.

Exposed concrete structure, polished concrete floors, and industrial steel windows reinforce the working character of the building, while warm timber linings in the residential levels provide domestic warmth above.
